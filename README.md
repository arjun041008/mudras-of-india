# Mudras of India

An interactive guide to the 250 hand mudras described in *Mudras of India* by Cain & Revital Carroll.
Drawn hands move into each mudra's pose; search by name, meaning or purpose ("headache", "can't sleep").

```
index.html            page structure
css/style.css         styling
js/mudras-data.js     the 250 mudras and 46 categories
js/poses.js           hand pose for each mudra
js/stage.js           the animated hand rig and info card
js/app.js             gallery, random button, deep links (#mudra-id)
js/thumbs.js          drawn gallery thumbnails
js/search.js          search and category filters
```

For study only; not medical advice.
